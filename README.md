# intSpLoiT Web GUI

![intSpLoiT Logo](https://github.com/intSpLoiT/intframework/blob/webgui/screenshots/IMG_20250201_195737.jpg)

**intSpLoiT Web GUI** is a modern web interface designed to streamline pentesting processes and provide a user-friendly experience. This GUI simplifies command-line usage and offers quick access to powerful pentesting tools.

---

## Features

- **Dynamic & Modern Interface**: Lightweight, fast, and visually appealing design.
- **Hacker-Themed Aesthetics**: Classic green/black color palette with smooth animations.
- **Quick Access**: Fast access to frequently used commands and modules via interactive buttons.
- **Mobile & Desktop Friendly**: Responsive design that works seamlessly across all devices.

---

## Installation
   ```bash
   git clone -b webgui https://github.com/intSpLoiT/intframework.git intframeworkweb
   cd intframeworkweb
   pip3 install -r requirements.txt
   python3 main.py
   ```
