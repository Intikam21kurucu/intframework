# ⚙️ Join the Core Developer Team of intSpLoiT

intSpLoiT Framework is not an ordinary framework where you only add modules. It features its own terminal interface, modular system, payload builder, database management, and virtual environments — all custom-built.

Therefore, we are looking for developers who can contribute to the **core architecture and system** of the framework in areas such as:

### 📌 Requirements:
- Advanced Python 3 proficiency  
- Experience developing console (terminal) interfaces  
- Understanding of file structure planning and module management logic  
- Knowledge of system Python modules like socket, subprocess, threading, os  
- Ability to work with structured data formats such as JSON and SQLite  
- Capability to directly modify and improve the framework’s core infrastructure  
- Responsible mindset to detect and fix bugs proactively

> **Note:** This team operates on a fully **volunteer** basis. There is no payment involved. Contributors will be credited within the framework.

### 👨‍💻 How to Join?

- Open a new GitHub Issue:  
  Title: `Core Developer Application: Your Full Name or Nickname`

- In the issue description, please include:  
  - Your real name or nickname (both are acceptable)  
  - Brief introduction and your skills  
  - What you want to contribute to intSpLoiT (e.g., terminal development, structure design)  
  - Your GitHub username  
  - Your contact email address (optional but recommended)  
  - Any example projects or portfolios if available

Approved applicants will be added to a special team and will help steer the core development of the framework.

> Come build the backbone of the framework with us.
